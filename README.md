# Personalised Book Recommendation System

A book recommendation system using collaborative and content-based filtering techniques.

## Features
- Popularity-based recommendations
- User similarity based recommendations
- Cold-start handling for new users

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Flask

## Recommendation Techniques
- Cosine Similarity
- Collaborative Filtering

## Note
Due to size constraints, datasets and trained models are not included.
They can be generated by running the training notebook.
